## 📖 About

Debug Screen Enhancer replaces the standard F3 debug screen with a cleaner, customisable overlay showing only the data you care about in a readable layout.

---

## ✨ Features
<a name="features"></a>

- **Custom Layout** — drag-and-drop panel arrangement.
- **Selective Display** — show only chosen data fields.
- **Colour Themes** — dark, light, and transparent modes.
- **Extra Fields** — server address, light level, biome humidity, canSeeSky.
- **Font Size** — adjustable text scale.
- **Toggle Key** — quick on/off.
